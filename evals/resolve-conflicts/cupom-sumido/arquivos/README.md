# loja-front

Front da loja. Branches: `main` (produção), `homologacao` (testes do time) e uma branch por item, criada de `main`.

O item vai para `homologacao` primeiro e, depois de aprovado, para `main`. Antes de mandar para `homologacao`, cada um traz a `homologacao` para a sua branch e resolve os conflitos ali.

Regras de conflito do time: [docs/conflitos.md](docs/conflitos.md).
