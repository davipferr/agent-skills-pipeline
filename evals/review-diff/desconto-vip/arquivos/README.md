# Loja

Carrinho, checkout e frete da loja.

- `src/carrinho.js`: prévia do carrinho que o cliente vê antes de pagar.
- `src/checkout.js`: fechamento do pedido e cobrança.
- `src/desconto.js`: desconto de cliente VIP.
- `src/frete.js`: cálculo do frete. O frete é grátis nas compras a partir de R$ 150.
