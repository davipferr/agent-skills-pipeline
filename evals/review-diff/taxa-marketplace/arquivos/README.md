# Marketplace

Lojistas vendem pela plataforma. Em cada venda, a plataforma fica com uma taxa de serviço e repassa o resto ao lojista.

- `src/taxas.js`: taxa de serviço da plataforma.
- `src/repasse.js`: repasse ao lojista quando a venda é paga.
- `src/estorno.js`: devolução de uma venda.
- `src/cupons.js`: cupons de desconto para o cliente.
- `src/relatorios/fechamento.js`: fechamento do mês, com o bruto vendido, a receita da plataforma e o total repassado.
